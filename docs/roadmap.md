# Roadmap

## Phase 1 — Current repository

Deterministic agent boundaries, human approval, structured evidence, and CI. This gives the project a credential-free baseline that always runs.

## Phase 2 — LLM provider adapter

Replace selected deterministic agents with an Azure AI Foundry/Semantic Kernel-backed implementation while preserving the same structured contracts. Keep the deterministic implementation for CI and regression comparison.

## Phase 3 — Track 5 handoff

Map approved automation specifications to concrete Postman/Newman or Playwright tests and return execution evidence to the QA report.

## Phase 4 — Evaluation

Score scenario completeness, traceability, unsupported assumptions, duplicate scenarios, and stability across repeated runs.
